# Security policy

Themis is designed to operate on production clusters, so security reports are taken seriously.

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's **Report a vulnerability** button on the repository's Security tab. Do not open a public issue.

Include the affected component and version, steps to reproduce, and the impact you observed. You should receive an acknowledgement within a few days.

## Supported versions

Themis has not yet had a release. Until it does, only the `main` branch is supported.
